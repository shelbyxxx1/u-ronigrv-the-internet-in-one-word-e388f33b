One sentence describing the entry: a program that writes the single word "lore" — the whole internet, in one word — to /output/entry.txt. Uses only the Python standard library, with no network access or secrets.

## Run

```sh
python3 main.py
```

Writes the word below plus one trailing newline to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to a non-empty directory path to write `entry.txt` there instead. Parent directories are created as needed; the repository can remain read-only.

## The word

> lore
